# ops-backup-drill

Follow the `ops-backup-drill` playbook in `docs/ops-guide.md` in the orchestra repository (from this skill's folder: `../../../docs/ops-guide.md`). A backup that has not been restored is a hope; record the date, size, duration and what was compared.
