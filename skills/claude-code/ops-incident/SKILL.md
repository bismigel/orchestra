# ops-incident

Follow the Incidents section in `docs/ops-guide.md` in the orchestra repository (from this skill's folder: `../../../docs/ops-guide.md`). This is orchestrator-only work: do not delegate to workers during an incident. Verify each claim with a command before stating it; a hand fix is said aloud and turned into a PR immediately.
